# API Documentation

## Endpoints (coming soon)

This document will contain all API endpoints for the Teradyne Robotics Inventory System.

### Authentication
- POST /api/auth/login
- POST /api/auth/register
- POST /api/auth/logout

### Robots
- GET /api/robots
- POST /api/robots
- GET /api/robots/:id
- PUT /api/robots/:id
- DELETE /api/robots/:id

### Loans
- GET /api/prestamos
- POST /api/prestamos
- GET /api/prestamos/:id
- PUT /api/prestamos/:id

### Users
- GET /api/usuarios
- POST /api/usuarios
- GET /api/usuarios/:id
- PUT /api/usuarios/:id
